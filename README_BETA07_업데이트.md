# RAINFOREST MEMORIES BY PLANT MATTER — BETA 07

## BETA 06에서 변경된 내용

### 식물 관찰 기록
- **위치는 지도에서 찍거나 GPS로 등록합니다.** 위도·경도를 직접 입력하는 칸을 없앴습니다.
  - 지도를 누르면 핀이 생기고, 핀을 끌어서 미세 조정할 수 있습니다.
  - **현재 위치로 찍기**를 누르면 GPS 좌표와 정확도(±m), 고도가 자동으로 기록됩니다.
  - 위치는 선택 사항입니다. **위치 지우기**로 위치 없이도 저장할 수 있습니다.
  - 지도를 불러오지 못하는 오프라인 현장에서도 GPS 버튼은 작동합니다.
- **발견 날짜와 시각을 직접 설정합니다** (`03 / DATE & TIME` 구역).
  - 기본값은 지금이며, 나중에 기록할 때는 실제 발견 일시로 바꿀 수 있습니다.
  - **시각 모름**을 누르면 날짜만 기록됩니다.
  - 미래 날짜는 저장되지 않습니다.
  - 기존 기록도 수정 화면에서 날짜와 시각을 바꿀 수 있습니다.
- 상세 화면에 **관찰 일시**(시각 포함)와 **위치 기록 방식**(GPS / 지도에서 선택)을 표시합니다.

### 비공개 전환
- 관찰 기록 상세 화면에 **공개 범위** 구역이 생겼습니다.
  - **비공개 · 이 기기에만 저장**: 아직 공유하지 않은 기록 (기존과 동일)
  - **공개 중**: 베타 멤버에게 보이는 기록 → **비공개로 전환** 버튼
  - **비공개 · 나만 보기**: 온라인에 보관되지만 다른 멤버에게 보이지 않는 기록 → **다시 공개하기** 버튼
- 비공개로 전환하면 다른 멤버에게는 **피드, 지도, 사진, 좋아요, 댓글, 동정 의견이 모두 보이지 않습니다.** 서버 데이터베이스 권한(RLS)으로 막기 때문에 앱을 우회해도 볼 수 없습니다.
- 다시 공개하면 기존 좋아요와 댓글이 그대로 돌아옵니다 (삭제되지 않음).
- 비공개 전환은 인터넷 연결이 필요하며, 서버에서 처리가 확인된 뒤에만 "비공개"로 표시됩니다.
- PROFILE의 내 기록 목록에서 비공개 기록에는 `PRIVATE` 표시가 붙습니다.

### 식물 공간(공방·매장·작업실)
- **주소 검색으로 등록합니다.** 좌표 입력 칸을 없앴습니다.
  - 주소를 검색해 결과를 고르면 지도에 핀이 생기고, 국가와 지역이 자동으로 입력됩니다.
  - 핀을 끌어 정확한 입구 위치로 조정할 수 있습니다.
  - **상세 주소**(층·호수) 칸을 추가했습니다.
- **보유 식물은 공간을 만든 뒤 따로 하나씩 등록합니다.**
  - 공간 상세 화면 또는 PROFILE의 `＋ 식물` 버튼에서 추가합니다.
  - 입력 항목: 사진, 학명, 원산지·자생지, 적정 온도(최저–최고), 적정 습도(최저–최고), 분양 상태(분양 가능 / 예약 중 / 전시·보유), 분양 메모.
  - 등록한 식물은 수정·삭제할 수 있고, 사진은 크기를 줄이고 EXIF 위치 정보를 제거한 뒤 올라갑니다.
  - 공간 상세 화면에 식물 카드(사진, 학명, 원산지, 온도·습도)로 표시됩니다.
- 지도 검색에서 **보유 식물 학명으로도 공간을 찾을 수 있습니다.**
- 공간 상세 화면에 주소와 **지도 앱에서 길찾기** 링크를 표시합니다.
- BETA 06에서 텍스트로 적은 보유 식물 목록은 사라지지 않습니다.
  - 상세 화면에 "이전 방식으로 등록된 목록"으로 계속 표시됩니다.
  - 장소 수정 화면에서 그 목록을 비울 수 있습니다.

### 기타
- 계정 삭제 서버 함수(`delete-account`)가 이제 사용자가 올린 사진(관찰 사진·보유 식물 사진)도 함께 삭제합니다. 함수를 이미 배포했다면 **다시 배포**해야 적용됩니다.

## 설치 순서 (기존 기록 보존)

1. 기존 앱의 **PROFILE → JSON 내보내기**로 백업하세요. JSON에는 정확한 GPS 좌표가 들어 있으니 외부에 공유하지 마세요.
2. ZIP을 풀어 GitHub 저장소 `im2beom/plant-matter-field`의 `main` 브랜치 최상위에 업로드하고 **Commit changes**를 누르세요.
   - **`config.js`는 삭제하거나 덮어쓰지 마세요.** ZIP에는 포함되어 있지 않습니다.
3. Supabase **SQL Editor**에서 `supabase/beta07_private_places.sql` 전체를 새 쿼리로 붙여 넣고 **Run**을 누르세요.
   - BETA 04 스키마, BETA 05 권한 복구 SQL, BETA 06 SQL이 먼저 적용되어 있어야 합니다.
   - 여러 번 실행해도 안전합니다.
   - 적용 확인: Table Editor에 `place_plants` 테이블이 있고, Storage에 `place-photos` 버킷이 있으면 됩니다.
4. GitHub Actions / Pages 배포가 초록색 체크인지 확인하고 앱을 새로고침하세요. 홈 화면 앱(PWA)은 완전히 종료한 뒤 다시 여세요. 상단에 `BETA 07`이 보이면 새 버전입니다.
   - **웹사이트 데이터 삭제는 기기 기록을 지울 수 있으니 하지 마세요.**
5. (선택) `delete-account` 함수를 배포해 두었다면 다시 배포하세요: `supabase functions deploy delete-account`

**SQL을 실행하기 전에는:**
- 일반 기록 공유와 동기화는 기존처럼 작동합니다.
- 비공개 전환, 주소 기반 공간 등록, 보유 식물 등록은 "BETA 07 SQL을 적용하세요"라는 안내가 뜨고 실행되지 않습니다.

## 알아두기

- **주소 검색은 OpenStreetMap(Nominatim) 무료 검색을 사용합니다.**
  - 한국 도로명 주소 중 건물 번호까지는 검색되지 않는 곳이 있습니다. 그럴 때는 도로명이나 동 이름으로 검색한 뒤 지도에서 핀을 옮기면 됩니다.
  - 이 서비스는 초당 1회 이하 요청, 소규모 사용을 조건으로 합니다. 지금 베타 규모에는 문제없지만, **정식 출시 전에는 카카오 로컬 API나 행정안전부 도로명주소 API(API 키 필요)로 바꾸는 것을 권장합니다.**
- 비공개로 전환하기 직전에 다른 사람이 이미 받은 사진 링크는 최대 1시간까지 유효합니다 (서명 URL 만료 시간).
- 다른 사람의 기기에서는 새로고침하거나 다시 접속하기 전까지 방금 비공개로 바꾼 기록이 잠시 남아 보일 수 있습니다. 좋아요·댓글·동정 의견 같은 새 상호작용은 서버에서 즉시 차단됩니다.
- 공간 주소와 위치, 보유 식물은 베타 멤버에게 공개됩니다. 야생식물 채집 장소는 등록하지 마세요.
- `terms.html`, `privacy.html`은 여전히 법률 검토가 필요한 초안입니다.

## 검증 범위

- `node --check`로 `app.js`, `i18n.js` 구문 검사를 마쳤습니다.
- **SQL:** 로컬 PostgreSQL 16에 Supabase 구조를 흉내 낸 환경을 만들어 BETA 04 → 05 → 06 → 07 SQL을 차례로 실행했고, BETA 07 재실행도 확인했습니다. 다음 권한 동작을 두 명의 멤버와 비초대 계정으로 확인했습니다.
  - 비공개 기록과 그 기록의 댓글·좋아요·사진이 다른 멤버에게 보이지 않음
  - 비공개 기록에 다른 멤버가 좋아요·댓글·동정 의견을 달 수 없음
  - 작성자는 비공개 기록을 계속 보고 수정할 수 있음
  - 다른 사람의 공간에 식물을 추가하거나, 남의 식물을 수정할 수 없음
  - 다른 사람의 사진 폴더에 업로드할 수 없음
  - 공간을 삭제하면 보유 식물도 함께 삭제됨
- **화면:** Playwright(Chromium, 아이폰 크기 화면)로 48개 항목을 자동 테스트해 모두 통과했습니다. Supabase는 메모리 안의 가짜 서버로, 주소 검색은 고정된 응답으로 대신했습니다.
  - 지도 탭으로 위치 지정, GPS로 위치 지정, 날짜·시각 저장과 수정, 미래 날짜 차단
  - 공유 → 비공개 → 다시 공개, 홈 피드에서 비공개 기록 제외
  - 주소 검색(Enter 키 포함) → 공간 등록 → 사진 포함 식물 등록·수정, 온도 범위 오류 차단
  - 지도 팝업의 식물 수, 식물 학명으로 공간 검색
  - 영어 화면, BETA 07 SQL 미적용 안내
  - 지도 라이브러리를 불러오지 못하는 오프라인 상황에서도 GPS 기록과 저장이 되는지
- **미검증:**
  - 실제 Supabase 프로젝트에 SQL 적용
  - 실제 Nominatim의 한국 주소 검색 품질
  - 아이폰 Safari / PWA에서의 지도 터치와 날짜·시각 선택기 동작
  - 실제 GitHub Pages 배포

  정식 운영 전에 실기기에서 확인해 주세요.
