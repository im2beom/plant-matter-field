# RAINFOREST MEMORIES BY PLANT MATTER — BETA 06

## BETA 05에서 변경된 내용

- **홈 화면 = 인기 식물 피드**. 공개된 베타 관찰 기록을 좋아요 많은 순으로 표시하고 최신순으로 전환할 수 있습니다. 실제 게시물이 없으면 빈 피드를 안내하며 DEMO 기록은 인기순에 넣지 않습니다.
- **좋아요 · 댓글**. 승인된 베타 멤버가 온라인 공유된 식물에 좋아요를 누르거나 댓글을 달고 본인 댓글을 삭제할 수 있습니다.
- **식물 공간 지도**. 공방/매장/작업실 이름, 설명, 좌표, 보유 식물 목록을 등록·수정·삭제할 수 있습니다. 지도에서 별도의 초록색 사각 마커로 나타납니다. 좌표는 베타 멤버에게 공개되므로 실제 공개 가능한 영업·작업 공간만 등록하세요.
- **지도 이동 경계 제한**. 이퀄 어스 지도의 뷰포트가 바깥으로 벗어나지 않도록 제한하고, 상세 지도(Leaflet)의 반복 세계지도 및 경계 밖 이동도 억제했습니다.
- **사진 추가 UI 단순화**. 녹색 장식을 없애고 중립적인 `+` 형태로 변경했습니다. 영역 전체를 탭하거나 클릭해 사진을 선택할 수 있습니다.
- **한국어 / 영어 / 일본어**. 기기 언어가 `ko`, `en`, `ja`인 경우 자동 선택되며, OPTIONS → 언어 설정에서 직접 변경할 수 있습니다. 주요 UI 문구를 번역했습니다. 관찰자가 입력한 학명·메모 등 사용자 데이터는 번역하지 않습니다. 일부 세부/기존 화면의 고정 문구는 여전히 한국어로 남을 수 있습니다.
- **설정 화면 접기**. 언어, 지도, 계정·개인정보, 온라인 베타, 앱 정보를 개별 접이식 구역으로 정리했습니다.

## 설치: 기존 기록을 안전하게 유지하는 순서

1. **기존 앱의 PROFILE → JSON 내보내기로 기록을 백업**하세요. JSON에 개인 GPS, 사진, 탐사 경로가 포함될 수 있으니 외부에 공개하지 마세요.
2. ZIP을 압축 해제해 내부 파일과 폴더를 GitHub 저장소 `https://github.com/im2beom/plant-matter-field`의 `main` 브랜치 최상위에 업로드하고 **Commit changes**를 실행하세요. 기존 파일을 대체하되 **현재 사용 중인 `config.js`는 삭제하거나 덮어쓰지 마세요.** ZIP은 보안상 `config.js`를 포함하지 않습니다.
3. Supabase **SQL Editor**에서 기존 BETA 04 스키마 및 BETA 05 권한 복구 SQL이 먼저 정상 적용된 상태인지 확인한 뒤, 이번 패키지의 `supabase/beta06_social_places.sql` 전체를 새 쿼리로 붙여 넣고 `Run`을 누르세요. `field_likes`, `field_comments`, `botanical_places` 세 테이블 생성과 RLS 정책 적용이 필요합니다.
4. GitHub Actions / Pages 배포 성공을 확인하고 `https://im2beom.github.io/plant-matter-field/` 에서 새로고침하세요. PWA가 구버전이면 앱 완전 종료 후 다시 열고, Safari에서 새로고침하세요. **웹사이트 데이터 삭제는 개인 기록을 날릴 수 있으므로 피하세요.**
5. 승인된 베타 계정으로 접속한 뒤 공개 관찰 기록의 좋아요/댓글, PROFILE에서 장소 등록, MAP에서 초록색 장소 핀, OPTIONS에서 언어 선택을 확인하세요.

**중요:** 코드를 업로드하는 것과 Supabase SQL 실행은 별도 작업입니다. SQL을 실행하기 전에는 좋아요·댓글·장소 등록이 활성화되지 않습니다. 기존 Google 로그인 권한 오류가 남아 있다면 BETA 05의 인증 복구 SQL/초대 계정 설정부터 확인하세요. 이번 BETA 06 SQL만으로 기존 인증 문제까지 자동 해결되지는 않습니다.

## 기존 저장소와 개인정보

- 기존 IndexedDB 저장소 이름 `plant-matter-field` 및 버전 `2`를 **그대로 유지**하므로 업데이트가 기존 기기 기록을 의도적으로 삭제하지 않습니다.
- 관찰 기록의 공개 범위, 기존 베타 초대 방식, 사진 선택 홍보 동의, 탐사 GPS 저장 방식 등 기존 동작을 유지합니다.
- **야생식물 정확한 채집 좌표를 댓글이나 장소 등록란에 게시하지 마세요.** 식물 공간의 이름·좌표·보유 식물은 승인을 받은 베타 참여자가 볼 수 있습니다.
- `terms.html`, `privacy.html`은 현재도 **운영 전 법률 검토가 필요한 초안**입니다. 공개 정식 서비스 전에 개인정보 처리방침·약관을 완성해야 합니다.
- 계정 완전 삭제 기능은 BETA 05에서 안내된 별도 서버 함수 배포가 필요합니다.

- Node 모의 DOM 기반 자동 정적 테스트에서 홈 빈 상태/인기순 정렬, 좋아요 버튼, 장소 마커, 지도 뷰포트 경계, 단순화 사진 UI, 설정 메뉴, 언어 문자열, 새 SQL 테이블·RLS 존재 검사를 통과했습니다.
