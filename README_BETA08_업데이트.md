# RAINFOREST MEMORIES BY PLANT MATTER — BETA 08

## BETA 07에서 변경된 내용

### 동정 완료
- 관찰 기록의 동정 상태에 **동정 완료**를 추가했습니다.
  - 기록 수정 화면의 `동정 상태`에서 고를 수 있습니다.
  - 내 기록 상세 화면에서 **✓ 동정 완료로 변경** 버튼으로 바로 바꿀 수 있습니다.
  - 받은 동정 의견 옆의 **이 학명으로 동정 완료**를 누르면 그 학명으로 바꾸면서 동정 완료 처리됩니다.
  - **동정 완료 취소**로 되돌릴 수 있습니다.
  - 동정 완료된 기록에 새 동정 의견이 달려도 상태가 내려가지 않습니다.
- 공간의 보유 식물에도 `동정 상태`(미동정 / 동정 완료)를 추가했습니다. 동정 완료 식물에는 `✓ 동정 완료` 표시가 붙습니다.

### 프로필 사진
- PROFILE 상단에서 **프로필 사진 등록 / 변경 / 삭제**를 할 수 있습니다.
- 사진은 항상 **1:1 정사각형(512×512)** 으로 저장됩니다. 비율이 다르면 **가운데를 기준으로 자동으로 잘립니다**.
- 저장할 때 EXIF 정보(촬영 위치 포함)는 제거됩니다.
- 프로필 사진은 승인된 베타 멤버에게만 보입니다 (비공개 저장소 + 1시간짜리 서명 링크).

### 고유 이름
- **이름은 다른 이용자와 중복될 수 없습니다.** 대소문자와 앞뒤 공백은 구분하지 않습니다 (`Moss`와 `moss `는 같은 이름).
- 규칙: 2~30자, `@` 사용 불가.
- OPTIONS에서 이름을 입력하면 바로 **사용 가능 / 이미 사용 중**을 알려 줍니다. 서버에서도 한 번 더 막습니다.
- **기존 중복 이름 처리:** SQL을 실행하면 같은 이름이 이미 여러 개 있을 경우 가장 먼저 설정을 마친 계정이 그 이름을 유지합니다. 나머지는 이름 뒤에 `_` + 계정 ID 5글자가 붙습니다 (예: `moss_bbbbb`). 해당 이용자는 OPTIONS에서 다시 바꿀 수 있습니다.
- **새 가입자 기본 이름 변경:** 지금까지는 이메일 앞부분이 기본 이름으로 들어갔습니다. 이름이 검색되면 이메일 일부가 노출되므로, 이제 새 가입자는 첫 설정 화면에서 이름을 직접 정합니다.

### 이용자 검색
- HOME의 **이용자 찾기**에서 검색합니다.
  - **이름:** 일부만 입력해도 찾을 수 있습니다.
  - **이메일:** 로그인 이메일 주소 전체가 정확히 일치해야 찾을 수 있습니다.
  - 검색 결과에 로그인 이메일은 표시되지 않습니다. 본인이 공개를 선택한 이메일만 보입니다.
- 검색 대상은 첫 설정을 마친 승인 베타 멤버뿐입니다. 승인되지 않은 계정은 검색할 수도, 검색될 수도 없습니다.
- 홈 피드 카드, 관찰 기록 상세, 공간 상세에 **작성자 이름 칩**이 생겼고, 댓글 작성자 이름도 누를 수 있습니다. 누르면 그 사람의 도감이 열립니다.

### 개인 식물 도감
이용자를 누르면 그 사람의 도감이 열립니다.
- **요약:** 발견 기록 수, 발견한 종 수, 보유 종 수, 공간 수
- **자연에서 발견한 식물:** 처음 발견한 것부터 `No.001`, `No.002`… 순서로 사진 타일이 보입니다. 동정 완료된 종에는 `✓ 동정 완료`가 붙습니다. 비공개로 전환한 기록은 다른 사람의 도감에 나오지 않습니다.
- **보유 식물:** 그 사람이 등록한 공방·작업실별로 보유 식물 목록이 묶여 보입니다 (BETA 07 보유 식물 데이터와 연동).
- **공방 · 작업실 위치:** 작은 지도에 핀으로 표시되고, 주소와 **공간 보기 / 길찾기** 버튼이 있습니다.
- **공개 연락처:** 본인이 공개에 동의한 이메일과 전화번호만 보입니다. 누르면 메일이나 전화로 바로 연결됩니다.
- 도감에서 기록이나 공간을 열면 **← 도감** 버튼으로 다시 돌아올 수 있습니다.
- PROFILE의 **내 도감 보기**로 내 도감이 다른 멤버에게 어떻게 보이는지 확인할 수 있습니다. `PRIVATE` 표시는 나에게만 보입니다.

### 기타
- 계정 삭제 서버 함수가 프로필 사진도 함께 삭제합니다. 배포해 두셨다면 다시 배포하세요.

## 설치 순서

1. 기존 앱 **PROFILE → JSON 내보내기**로 백업하세요.
2. ZIP을 풀어 파일과 `supabase` 폴더를 GitHub에 올리고 **Commit changes**를 누르세요.
   - 업로드 페이지: https://github.com/im2beom/plant-matter-field/upload/main
   - **`config.js`는 덮어쓰지 마세요.** ZIP에는 포함되어 있지 않습니다.
3. Supabase **SQL Editor**에서 `supabase/beta08_people_dex.sql` 전체를 실행하세요.
   - BETA 07 SQL(`beta07_private_places.sql`)이 먼저 적용되어 있어야 합니다.
   - 여러 번 실행해도 안전합니다.
   - 확인: Storage에 `avatars` 버킷이 생기면 됩니다.
4. 배포 상태를 확인한 뒤(https://github.com/im2beom/plant-matter-field/actions) 앱을 새로고침하세요. 상단에 `BETA 08`이 보이면 됩니다.
5. (선택) `delete-account` 함수를 다시 배포하세요.

**SQL 실행 전에는:**
- 기존 기능은 그대로 작동합니다.
- 관찰 기록의 동정 완료 처리는 SQL 없이도 됩니다.
- 프로필 사진과 이용자 검색은 "BETA 08 SQL을 적용하세요"라는 안내만 뜹니다.
- 보유 식물의 동정 상태 선택 칸은 나타나지 않습니다.

## 알아두기

- 도감의 발견 기록은 이용자당 최대 500개, 보유 식물은 1,000개까지 불러옵니다.
- 다른 사람의 도감에는 공유한 기록만 나옵니다. 내 기기에만 저장된 기록은 나오지 않습니다.
- 비공개로 전환한 기록, 정확한 GPS 좌표, 로그인 이메일은 도감과 검색에 노출되지 않습니다 (서버 권한으로 차단).

## 검증 범위

- `node --check` 구문 검사를 통과했습니다.
- **SQL:** 로컬 PostgreSQL 16(Supabase 구조 모사)에서 BETA 04 → 08 SQL을 차례로 실행했고, BETA 08 재실행도 확인했습니다. 다음 동작을 확인했습니다.
  - 기존 중복 이름 정리
  - 대소문자가 다른 같은 이름 차단
  - 이미 있는 이름으로 가입해도 가입 자체는 실패하지 않음
  - 이름 일부 검색과 이메일 정확 일치 검색
  - 이메일 일부나 `%` 같은 와일드카드로는 검색되지 않음
  - 승인되지 않은 계정은 검색과 프로필 사진 열람이 막힘
  - 남의 프로필 사진 폴더 업로드와 남의 프로필 수정이 막힘
  - 보유 식물 동정 상태에 허용되지 않은 값이 들어가지 않음
- **화면:** Playwright(Chromium, 아이폰 크기 화면)로 자동 테스트를 돌려 모두 통과했습니다.
  - BETA 08 새 기능 33개 항목: 이용자 검색, 도감 통계·타일·지도·연락처, 도감 ↔ 상세 이동, 정사각형 512×512 프로필 사진, 중복 이름 차단, 동정 완료·취소·의견 채택, 보유 식물 동정 상태
  - BETA 07 기능 회귀 테스트 48개 항목
  - 오프라인(지도 없음) 상황
- **미검증:**
  - 실제 Supabase 적용
  - 아이폰 Safari/PWA에서의 사진 선택·자르기 실기기 동작
  - 실제 GitHub Pages 배포
