# RAINFOREST MEMORIES BY PLANT MATTER — BETA 12

## BETA 11에서 변경된 내용

### 화면
- **① 타이틀 크기:** 대분류 타이틀 5개를 약 20% 줄였습니다(휴대폰 기준 대문자 높이 약 22px → 17.5px). 5개 모두 같은 크기입니다. 상단 로고는 그대로이며 여전히 대분류보다 작습니다.
  - NEW PLANT RECORD는 이제 휴대폰(360px 이상)에서 한 줄로 들어갑니다.
- **② 타이틀 위치:** 5개 탭 모두 머리말과 타이틀 사이 간격, 시작 위치를 똑같이 맞췄습니다. 홈만 2px 다르던 문제를 고쳤습니다.
- **③ 홈 문구:** "열대의 기록, 일상에서 식물을 마주한 순간."
- **④ FIELD MAP 문구:** "학명, 지역, 그리고 식물을 위한 공간을 검색해 보세요."
- **⑪ 데모 식물 4개 삭제**
- **⑫ 개인 카테고리:** "나의 식물 활동" 제목 아래 **식물 수집 / 식물 재배 / 야생 관찰** (영어 Collector / Grower / Field Explorer)

### 관찰 기록 저장과 공개
- **⑤ 저장하면 자동으로 온라인 저장:** 승인된 멤버는 저장 즉시 온라인에 올라갑니다.
  - 오프라인이면 기기에 저장해 두었다가 인터넷이 연결되면 자동으로 올라갑니다.
  - 기록 화면의 **06 / SHARING**에서 **공개 / 비공개(나만 보기)**를 고릅니다. 기본은 공개입니다.
  - 정확한 위치는 기존 "위치 공개 수준"을 그대로 따릅니다.
- **기기에만 있던 이전 기록:** 자동으로 올리지 않습니다. PROFILE → 온라인 공유에서 **"기기에만 있는 기록 N개를 비공개로 온라인 백업"** 버튼으로 한 번에 올릴 수 있습니다.
- **⑥ 수정할 때 발견 지명이 사라지던 문제 수정:**
  - 위치를 "대략적인 지역"이나 "비공개"로 하면 발견 지명과 전문 항목(필드 번호, 관찰자, 개체군, 동반 식생, 표본)을 서버의 **본인만 볼 수 있는 칸**에 저장합니다.
  - 그래서 수정해도, 다른 기기에서 열어도 사라지지 않습니다.
  - 상세 화면에는 **"나만 보임"** 표시가 붙습니다.

### 지도와 발견 위치
- **⑩ 상세 화면 "발견 위치":**
  - 정확한 위치 공개: 작은 지도 + 지명
  - 대략적인 지역: **국가 중심 핀** + "국가 중심 표시 · 실제 발견 위치가 아닙니다"
  - 비공개: "위치 비공개"
  - 본인 기록은 항상 정확한 위치를 보여 주고 "나만 보임" 표시가 붙습니다.
  - 작은 지도를 누르면 MAP의 그 위치로 이동합니다.
- **대략적인 지역 기록의 지도 핀:** 약 100km 격자 중심 대신 **국가 중심**에 표시합니다. 위치 보호가 더 강해집니다.
  - 국가는 기기 안의 국가 경계 자료로 판별하며, 좌표를 외부로 보내지 않습니다.
  - 기존에 올린 기록도 앱을 열 때 자동으로 바뀝니다.
- **⑧ 겹친 핀:** 같은 위치의 기록·공간은 숫자가 적힌 핀 하나로 묶고, 누르면 목록이 나와 각각 열 수 있습니다.
- **⑦ 상세 화면 위에 "전체 화면" 버튼이 보이던 문제 수정**
- **⑨ 전체 화면 지도에서 공간·기록을 열면 지도에 가려지던 문제 수정:** 닫으면 보던 전체 화면 지도로 돌아갑니다.

### 사진
- **⑬ 사진 비율:** 가로 사진은 **16:9**, 세로·정사각형 사진은 **3:4**로 잘립니다. 긴 변은 최대 1600px입니다.
  - 관찰 기록, 보유 식물, 공방 사진에 모두 적용됩니다.
  - 슬라이드는 넘길 때마다 사진 비율에 맞춰 높이가 바뀝니다.
  - 피드와 입력 미리보기도 사진 전체를 보여 줍니다.
- **⑯ 보유 식물:**
  - 사진을 **최대 5장**까지 올릴 수 있습니다.
  - 공간이 2곳 이상이면 등록 화면에서 **어느 공간인지 선택**합니다. 수정할 때 다른 공간으로 옮길 수도 있습니다.
  - 카드를 누르면 사진 슬라이드가 있는 상세 화면이 열립니다.

### 계정과 탐사
- **⑭ 공간 운영자 → 개인 전환 시 확인 창:** 삭제될 공간 이름과 식물 개수를 보여 줍니다.
  - 동의하면 운영 공간과 보유 식물을 **한 번에 삭제한 뒤** 전환하고, 사진 파일도 지웁니다.
  - 실패하면 아무것도 바뀌지 않습니다.
  - 개인 공간은 그대로 남습니다.
- **⑰ 탐사 삭제:** 프로필 카드와 탐사 화면에 삭제 버튼이 있습니다. 연결된 관찰 기록은 남고 연결만 풀립니다.
- **⑱ 탐사 만들기:**
  - **시작 지점 → 경유지(＋ 추가) → 종료 지점** 순서로 만듭니다.
  - 각 지점은 **주소 검색 / 현재 위치 / 지도 핀**으로 정하고, 핀은 끌어서 옮길 수 있습니다.
  - 종료 지점은 "시작 지점과 같음(왕복)"을 고르거나 비워 둘 수 있습니다.
  - 기존 탐사도 같은 화면에서 수정합니다.
- **⑲ 탐사 공개 설정 (기본 비공개):**
  - 탐사 화면의 ⚙에서 **탐사 경로 공개**와 **GPS 이동 궤적 공개**를 따로 켭니다. 궤적은 경로를 공개해야 켤 수 있습니다.
  - 공개된 탐사는 그 사람의 도감에 **"탐사 기록"**으로 보이며, 경로 지도·궤적·연결된 공개 관찰 기록을 볼 수 있습니다.
  - 궤적은 모양을 유지하면서 최대 2,000개 지점으로 줄여 올립니다.
  - 비공개로 되돌리면 서버에서도 지웁니다. 비공개 탐사는 서버에 올라가지 않습니다.

## 설치 순서
1. 기존 앱 **PROFILE → 데이터 백업 → JSON 내보내기**로 백업하세요.
2. ZIP을 풀어 GitHub에 업로드하세요. 새 폴더 **`assets/geo`**(국가 자료)도 함께 올려야 합니다.
   - **`config.js`는 덮어쓰지 마세요.**
3. Supabase SQL Editor에서 실행하세요.
   - BETA 11까지 적용했다면: `supabase/beta12_sharing_expeditions.sql`
   - 확실하지 않다면: `supabase/beta07_to_12_combined.sql` (여러 번 실행해도 안전)
4. 상단에 `BETA 12`가 보이는지 확인하세요.

**SQL 실행 전에는:**
- 화면 변경, 자동 저장, 사진 비율, 겹친 핀, 탐사 만들기·삭제는 그대로 작동합니다.
- 다음 기능은 SQL 안내만 뜹니다: 본인만 보는 칸 저장, 국가 코드, 보유 식물 5장, 운영자→개인 전환, 탐사 공개.

## 검증 범위
- **SQL:** 로컬 PostgreSQL 16(Supabase 구조 모사)에서 확인했습니다.
  - BETA 12 SQL 2회 실행, 07~12 통합 SQL 반복 실행(새 DB·기존 DB) 모두 정상
  - 본인만 보는 칸을 다른 멤버가 읽거나 쓸 수 없음
  - 국가 코드 형식과 사진 5장 제한 확인
  - 운영자→개인 전환은 운영 공간과 그 식물만 삭제하고 개인 공간은 남김
  - 공개 탐사는 초대된 멤버만 보고, 다른 사람은 수정할 수 없음
- **화면:** Playwright(Chromium, 아이폰 크기) 자동 테스트 229개 항목을 모두 통과했습니다.
  - BETA 12 새 기능 52개 (요청 19개 각각)
  - 이전 기능 177개
  - 오프라인 테스트, 영어·일본어 번역 누락 점검
- **미검증:** 실제 Supabase 적용, 아이폰 Safari/PWA 실기기, 실제 주소 검색 품질
