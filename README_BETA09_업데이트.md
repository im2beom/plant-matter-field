# RAINFOREST MEMORIES BY PLANT MATTER — BETA 09

## BETA 08에서 변경된 내용

### PROFILE 탭 재구성
- 상단에 **[내 프로필] / [친구]** 전환 버튼을 만들었습니다.
- 각 항목은 OPTIONS 탭처럼 **제목을 눌러 펼치고 접는 방식**입니다. 펼침 상태는 기기에 기억됩니다.
- **내 프로필** 구성 (위에서부터):
  1. 프로필 사진·이름·통계 (항상 표시)
  2. 나의 관찰 식물 (기본으로 펼침)
  3. 나의 식물 공간
  4. 탐사 프로젝트
  5. 온라인 공유 · 업로드
  6. 데이터 백업
  - 온라인 공유와 백업은 관찰 식물 아래, 맨 마지막으로 옮겼습니다.
- **친구** 구성:
  - 친구 찾기 (이름 일부 또는 정확한 이메일)
  - 받은 친구 요청
  - 친구 목록
  - 보낸 친구 요청
- HOME에 있던 **이용자 찾기는 PROFILE → 친구 → 친구 찾기로 옮겼습니다.**

### 친구 기능
- 검색 결과나 상대 도감에서 **＋ 친구 추가**를 누르면 친구 요청이 보내집니다. 상대가 **수락**하면 친구가 됩니다.
- 받은 요청은 수락하거나 거절할 수 있습니다. 보낸 요청은 취소할 수 있고, 친구는 목록에서 삭제할 수 있습니다.
- 받은 요청이 있으면 하단 PROFILE 아이콘에 빨간 점이, [친구] 버튼에 숫자가 표시됩니다.
- 친구 이름을 누르면 그 친구의 도감(프로필)이 열립니다. 도감 상단에도 친구 상태가 표시됩니다.
- 친구 관계는 당사자 두 사람만 볼 수 있습니다. 요청은 승인된 베타 멤버에게만 보낼 수 있습니다.
- 참고: 지금은 친구가 아니어도 모든 베타 멤버가 공유된 기록과 도감을 볼 수 있습니다. "친구에게만 공개" 같은 공개 범위가 필요하면 다음 버전에서 추가할 수 있습니다.

### 사진 4:3 자동 자르기
- **식물 등록 사진**(관찰 기록, 보유 식물)은 가로 4:3 비율로, 가운데를 기준으로 자동으로 잘립니다. 최대 크기는 1400×1050입니다.
- 사진 선택 화면 미리보기도 4:3으로 표시됩니다.
- 이미 등록된 사진은 그대로 유지됩니다. 새로 올리는 사진부터 적용됩니다.

### 공방 대표 사진
- 공간 등록·수정 화면에서 **대표 사진을 최대 10장**까지 올릴 수 있습니다. 여러 장을 한 번에 고를 수 있습니다.
- 모든 사진은 가로 4:3으로 가운데를 기준으로 자동으로 잘립니다.
- **첫 번째 사진이 대표 사진**입니다.
  - 다른 사진의 **대표로** 버튼을 누르면 그 사진이 맨 앞으로 옵니다.
  - **✕**로 사진을 뺄 수 있습니다.
- 공간 상세 화면 맨 위에 사진이 옆으로 넘겨 보는 갤러리로 표시됩니다.
- 지도 팝업과 도감의 공간 목록에는 대표 사진이 나옵니다.
- 저장할 때 뺀 사진과 공간을 삭제할 때의 사진은 저장소에서도 함께 지워집니다.

### 수정
- **식물 등록 시 발견 날짜·시각 입력칸이 화면 밖으로 나가던 문제**를 고쳤습니다.
  - 원인: 아이폰 Safari의 날짜·시각 입력칸이 기본 최소 너비를 가지고 있어서 칸 너비를 넘어갔습니다.
  - 해결: 입력칸이 칸 너비에 맞게 줄어들도록 바꿨습니다. 아주 좁은 화면(340px 이하)에서는 날짜와 시각이 위아래로 배치됩니다.

## 설치 순서

1. 기존 앱 **PROFILE → 데이터 백업 → JSON 내보내기**로 백업하세요.
2. ZIP을 풀어 GitHub에 업로드하고 **Commit changes**를 누르세요.
   - 업로드 페이지: https://github.com/im2beom/plant-matter-field/upload/main
   - **`config.js`는 덮어쓰지 마세요.**

   - BETA 08 SQL이 먼저 적용되어 있어야 합니다.
   - 여러 번 실행해도 안전합니다.
   - 대시보드: https://supabase.com/dashboard/projects
4. 배포를 확인하고(https://github.com/im2beom/plant-matter-field/actions) 앱을 새로고침하세요. 상단에 `BETA 09`가 보이면 됩니다.

**SQL 실행 전에는:**
- 기존 기능과 PROFILE 새 구성, 4:3 자르기, 날짜칸 수정은 바로 적용됩니다.
- 친구 기능과 공방 대표 사진은 "BETA 09 SQL을 적용하세요"라는 안내만 뜹니다.

## 검증 범위

- `node --check` 구문 검사를 통과했습니다.
- **SQL:** 로컬 PostgreSQL 16(Supabase 구조 모사)에서 BETA 09 SQL을 두 번 실행해도 문제없었습니다. 다음 동작을 확인했습니다.
  - 초대받지 않은 계정에는 요청을 보낼 수 없음
  - 자기 자신에게 요청할 수 없음
  - 같은 두 사람 사이에 중복 요청이 생기지 않음
  - 받은 사람만 수락할 수 있음
  - 요청 대상(누구와 누구 사이인지)은 바꿀 수 없음
  - 제3자는 친구 관계를 보거나 삭제할 수 없음
  - 대표 사진이 11장이 되면 거부됨
- **화면:** Playwright(Chromium, 아이폰 크기 화면) 자동 테스트를 모두 통과했습니다.
  - BETA 09 새 기능 41개 항목
    - 320·360·375·390px 화면에서 날짜·시각 칸이 화면 안에 들어오는지
    - 프로필 구성 순서와 펼침 상태 기억
    - 친구 요청·수락·취소·삭제, 알림 표시
    - 4:3 자르기 (세로 사진, 정사각형 사진)
    - 대표 사진 10장 제한, 대표 지정, 삭제와 저장소 정리, 갤러리, 지도 팝업
  - BETA 08 기능 33개, BETA 07 기능 48개 회귀 테스트
  - 오프라인 테스트
