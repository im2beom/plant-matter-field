# PLANT MATTER RAINFOREST MEMORIES — BETA 04 (탐사 경로 기능 포함)

Windows + iPhone / GitHub Pages 설치형 웹앱(PWA) 테스트 패키지입니다. **IPA가 아니며 아직 GitHub에 자동 배포된 상태가 아닙니다.**

## 기존 앱을 업데이트하려면

1. 기존 아이폰 앱에서 **PROFILE → JSON 내보내기**로 우선 식물 관찰 기록을 백업하세요. BETA04에서는 탐사 프로젝트와 이동 경로도 함께 백업합니다.
2. 이 ZIP 압축을 풀고 그 안의 `index.html`, `app.js`, `styles.css`, `config.js`, `sw.js`, `manifest.webmanifest`, `assets` 폴더 등 **파일과 폴더 내부 내용 전체**를 기존 GitHub 저장소 최상위에 업로드하세요. ZIP 파일 자체를 올리지 마세요.
3. 저장소 `https://github.com/im2beom/plant-matter-field` → **Add file → Upload files → Commit changes**를 사용하면 됩니다. 파일명이 같은 경우 변경사항을 반영하세요.
4. **Actions → pages build and deployment**에서 성공 여부를 확인한 후 `https://im2beom.github.io/plant-matter-field/`에 접속하세요.
5. 앱을 새로 설치할 필요는 없습니다. Safari에서 새로고침한 후 기존 홈 화면 아이콘으로 다시 열면 됩니다. 업데이트가 보이지 않으면 앱을 완전히 종료한 후 다시 열어주세요.
6. 기존 Safari 사이트 데이터나 앱 데이터를 삭제하지 마세요. 기존 BETA 02/03과 같은 IndexedDB 관찰 저장소를 사용합니다.

## 새 기능 (BETA 04)

- **5개 하단 탭:** HOME / MAP(기존 EXPLORE 통합) / RECORD / PROFILE / OPTIONS
- 관찰 사진 전체화면 확대; 현재 사진의 터치 확대·이동 지원
- 위치 공개 수준 라디오 버튼 UI 크기 수정
- 이퀄 어스·메르카토르 지도 전환, 확대·축소, 전체화면, 관찰 스팟 및 미리보기
- 관찰 작성 **자동 임시 저장**, 기기 내 오프라인 관찰 기록
- 탐사 프로젝트 생성 및 프로젝트와 관찰 기록 연결
- **탐사 이동 일지:** PROFILE → EXPEDITIONS → 해당 프로젝트 **이동 경로 / 일정**
- **출발지·경유지·목적지:** 장소 이름, 도착/출발 날짜, 좌표, 메모를 입력해 방문 순서대로 번호가 붙은 지도 마커로 표시합니다. 마지막 지점은 목적지로 표시되며 위·아래 버튼으로 경유 순서를 변경할 수 있습니다.
- **지도에서 지점 선택:** 이동 일지 지도에서 원하는 위치를 누르면 위도/경도가 입력됩니다. `현재 위치` 버튼으로 GPS 좌표도 가져올 수 있습니다.
- **연결선:** 각 방문 지점을 회색 점선으로 자동 연결합니다. **이 점선은 실제 도로·등산로를 계산한 경로가 아닙니다.** 도로를 따라가는 자동 경로 계산은 별도의 라우팅 API가 필요합니다.
- **실제 GPS 이동 궤적 (실험적):** 앱을 켜둔 상태에서 `GPS 기록 시작`을 누르면 위치 변화를 기기에 저장하고 녹색 실선으로 표시합니다. PWA는 화면이 꺼지거나 백그라운드가 되면 추적이 중단될 수 있어, 장시간 탐사용 신뢰성은 검증되지 않았습니다.
- **GPX 내보내기:** 경유 지점과 실제 GPS 이동 궤적을 GPX 파일로 저장할 수 있습니다.
- **JSON 내보내기/가져오기:** 관찰 기록뿐 아니라 탐사 프로젝트·이동 지점·GPS 기록까지 백업/복원합니다. 이전 버전 JSON 가져오기도 지원합니다.

## 오프라인과 개인정보

- 방문 지점, GPS 좌표, 이동 궤적은 기본적으로 **해당 기기의 IndexedDB에만 저장**됩니다. 온라인 식물 공유 계정을 연결해도 탐사 이동 경로는 자동으로 공개하거나 서버에 업로드하지 않습니다.
- 민감한 식물 관찰 좌표와 이동 동선을 보호하기 위해 GPX·JSON 내보내기 전에 정확한 좌표 포함 경고가 표시됩니다.
- 앱 화면과 기록 자체는 오프라인으로 열고 입력할 수 있지만 **상세 지도 타일 및 지도 라이브러리의 최초 로딩은 인터넷이 필요**합니다. 지도 타일 오프라인 다운로드, 산길 자동 계산은 지원하지 않습니다.
- 아이폰 GPS 추적은 반드시 사용자가 직접 시작해야 하며, 앱 화면이 백그라운드가 되면 중단하도록 구성했습니다. GPS 정확도 100m 초과인 점은 기록하지 않습니다. 야외 현장 테스트를 진행하세요.

## 지인들과 온라인으로 테스트하기

이 패키지는 온라인 베타를 위한 **Supabase 클라이언트 코드와 SQL 준비물**을 포함하지만 **서버가 아직 연결된 것은 아닙니다.** GitHub Pages 사이트 주소를 공유하면 친구들이 앱 화면을 열어 로컬 기능을 시험할 수 있으나, **서로 다른 아이폰의 식물 기록이 자동으로 공유되는 것은 아닙니다.**

### Supabase 연결 단계

1. [Supabase](https://supabase.com/) 프로젝트를 직접 생성합니다.
2. Supabase 프로젝트 SQL Editor에서 `supabase/schema_online_beta04.sql` 내용을 검토하여 적용합니다. 실제 데이터를 올리기 전에는 RLS 접근 정책을 반드시 검증하세요.
3. Supabase Dashboard → **Authentication**에서 이메일 로그인 활성화, Google 로그인은 별도 Google OAuth 설정이 필요합니다.
4. Site URL과 허용 Redirect URL에 GitHub Pages 배포 URL을 추가합니다.
5. `config.js`에 프로젝트의 **공개 URL**과 **publishable/anon 키**만 입력하고 GitHub에 다시 업로드합니다. `service_role` 등의 비밀키는 절대 업로드하지 마세요.
6. Supabase SQL Editor에서 아래처럼 테스트 참여자 이메일을 승인할 수 있습니다. 회원가입 여부와 승인 여부는 별개입니다.

```sql
insert into public.beta_invites (email)
values ('tester@example.com')
on conflict (email) do nothing;
```

7. 참여자들이 각자 로그인한 뒤 **지인 그룹에 관찰 기록 공유**를 직접 선택해야 공유 기록이 올라갑니다. 비공개 정확 GPS는 서버의 비공개 테이블에 분리하는 구조이며, 초기 운영 전 정책을 검토하세요.

**주의:** GitHub Pages 웹사이트와 소스코드는 일반적으로 공개 접근 가능하며, 위 이메일 승인 목록은 Supabase 데이터 접근만 제한합니다. 앱 링크 자체를 완전히 비공개로 제한하지는 않습니다.

### 아직 연결되지 않거나 검증하지 못한 기능

- 실제 Google/이메일 회원가입과 다중 기기 온라인 공동 관찰: Supabase 프로젝트·Google OAuth 설정 전에는 미작동
- 계정 삭제: 보안된 서버 측 삭제 함수 추가 필요
- 이동 경로 자체의 테스터 간 공유 및 실시간 동기화: 이번 버전은 **개인 기기 전용**
- 도로·등산로를 따라 붙는 경로 탐색, 앱이 꺼진 동안의 안정적인 GPS 추적: 미지원
- 실제 iPhone Safari 실기기 테스트: 미실시

### 테스트 결과

- JavaScript 구문 검사 및 Node VM 스모크 테스트 통과
- 탐사 지점 추가, 정렬, 수정 UI 렌더링, 삭제, 위치 좌표 계산의 코드 수준 테스트 통과
- 현재 실행 환경에서 브라우저 네트워크 접근이 제한되어 실제 iPhone 화면·지도 타일·GPS 권한 테스트는 완료하지 못했습니다.

## 기술 구성

GitHub Pages + 정적 HTML/CSS/JavaScript(Pretendard Regular 400), IndexedDB, Leaflet/OpenStreetMap, Supabase(선택 연결), Equal Earth SVG.

공식 로고는 제공된 Illustrator 파일에서 변형 없이 출력한 PNG를 사용하며 1:1 앱 아이콘은 정사각형 캔버스에 여백만 추가했습니다. Illustrator 원본 파일과 폰트 파일은 공개 저장소에 포함하지 않습니다.
