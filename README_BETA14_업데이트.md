# RAINFOREST MEMORIES BY PLANT MATTER — BETA 14

## BETA 13에서 변경된 내용: 지도를 MapTiler로 교체 (B 방식)

**MapTiler 키를 `config.js`에 넣기 전까지는 지금처럼 OpenStreetMap 지도로 작동합니다.** 키를 넣으면 아래 기능이 켜집니다.

### 상세 지도 (지도 탭, 전체 화면)
- **MapTiler 벡터 지도**를 MapTiler 공식 Leaflet 플러그인으로 표시합니다.
- **지도 글자 언어가 앱 언어를 따라갑니다.** 한국어 / English / 日本語 (OPTIONS → 언어 설정)
- 지도 왼쪽 위에 **[지도] [지형] [위성]** 버튼이 생깁니다.
  - 지도: 회색 지도 (MapTiler Dataviz Light)
  - 지형: 등산·야외용 (Outdoor)
  - 위성: 위성 사진 + 지명 (Hybrid)
  - 선택은 기기에 저장됩니다.
- **지도를 한 번만 만들고 계속 재사용합니다.**
  - 검색, 핀 선택, 전체 화면 전환, 탭 이동, 언어·스타일 변경을 해도 새 지도를 만들지 않습니다.
  - MapTiler는 지도를 처음 열 때 **세션 1건**으로 셉니다. 확대·이동은 추가 비용이 없습니다.
- 세계 지도(이퀄 어스)는 그대로 앱이 직접 그립니다. MapTiler는 상세 지도로 들어갈 때만 불러옵니다.

### 작은 지도
- 대상: 발견 위치, 도감 공간 지도, 공간 등록, 위치 선택, 탐사 지도
- MapTiler 지도 이미지를 씁니다. 요청 수로 계산됩니다.
- **화면에 보일 때만 불러와서** 요청 수를 줄입니다.

### 주소 검색
- 공간 주소, 개인 공간 지역, 탐사 지점 검색을 **MapTiler 주소 검색**으로 바꿨습니다.
- 가게·장소 이름도 찾습니다.
- 개인 공간은 시·도 같은 지역만 검색됩니다.

### 그 밖에
- **MapTiler 로고:** 무료 요금제 조건에 따라 모든 지도 왼쪽 아래에 표시합니다.
  - 공식 플러그인의 자동 로고 기능이 현재 SDK 버전에서 작동하지 않아, 앱이 직접 넣습니다.
  - 유료 요금제로 바꾸면 `config.js`에 `maptilerLogo: false`를 추가해 끌 수 있습니다.
- **대체 지도:** WebGL을 쓸 수 없는 기기이거나 MapTiler 라이브러리를 불러오지 못하면 MapTiler 지도 이미지로 자동 전환합니다.
- **설정 화면:** OPTIONS → 지도 설정에 현재 지도 제공 서비스가 표시됩니다. 키가 제대로 들어갔는지 여기서 확인할 수 있습니다.
- **사용 통계 전송 끔:** MapTiler SDK의 사용 통계(telemetry) 전송을 껐습니다.
- **개인정보 안내(privacy.html):** "4-1. 지도·주소 검색" 항목을 추가했습니다. 지도를 볼 때 보이는 지역과 IP 주소가, 주소 검색 때 검색어가 MapTiler로 전송된다는 내용입니다. 정식 방침을 만들 때 검토해 주세요.

## 설치 순서
1. 기존 앱 **PROFILE → 데이터 백업 → JSON 내보내기**로 백업하세요.
2. ZIP을 풀어 GitHub에 업로드하세요.
   - 새 폴더 **`assets/js`**(파일 2개)도 함께 올려야 합니다.
   - **`config.js`는 덮어쓰지 마세요.**
3. 이번에는 **SQL이 없습니다.**
4. 상단에 `BETA 14`가 보이는지 확인하세요. 이 상태에서는 아직 OpenStreetMap 지도입니다.

## MapTiler 키 설정
1. https://cloud.maptiler.com 에 가입합니다. 무료 요금제는 카드 등록이 필요 없습니다.
2. **API keys**에서 키를 하나 만들고, **Allowed HTTP origins**에 `im2beom.github.io`를 추가합니다.
   - 다른 사이트에서 키를 쓰지 못하게 막는 설정입니다.
   - 나중에 다른 도메인을 쓰면 그 도메인도 추가하세요.
3. GitHub에서 **`config.js`를 열어 수정**합니다.
   - 기존 두 줄은 그대로 두고 `maptilerKey` 한 줄만 추가하세요.
   ```js
   window.PM_CONFIG = {
     supabaseUrl: '기존 값 그대로',
     supabasePublishableKey: '기존 값 그대로',
     maptilerKey: '여기에 MapTiler API 키'
   };
   ```
4. 앱을 새로고침하고 **OPTIONS → 지도 설정**에 "지도·주소 검색 제공: MapTiler"가 보이는지 확인합니다.
5. **MAP**에서 메르카토르 도법을 고르거나 이퀄 어스 지도를 깊게 확대해 상세 지도를 엽니다.
   - 왼쪽 위에 [지도] [지형] [위성]이 보이면 정상입니다.

이 키는 Supabase 키처럼 브라우저에 공개되는 키입니다. 그래서 2번의 허용 도메인 설정이 중요합니다.

- **정식 출시(상업용):**
  - Flex 요금제(약 월 $25~30)가 필요합니다.

- **이 앱에서 계산되는 방식:**
  - 상세 지도는 방문당 세션 1건입니다.
  - 작은 지도는 보일 때 지도 이미지 요청 몇 건입니다.
  - 주소 검색은 검색 1회당 1건입니다.

## 검증 범위
- **자동 테스트:** Playwright(Chromium, 아이폰 크기) 364개 항목을 모두 통과했습니다.
  - BETA 14 새 항목 44개. 가짜 MapTiler 키·서버와, npm의 같은 버전(SDK 3.11.2, 플러그인 4.1.1)으로 만든 테스트용 SDK를 썼습니다.
    - MapTiler 벡터 지도가 한 번만 만들어지는지, 검색·전체 화면·탭 이동 후에도 같은 지도인지
    - 세션 ID(`mtsid`) 포함, 통계 전송 없음, 언어·스타일 변경
    - 작은 지도가 화면에 보일 때만 지도 이미지를 부르는지
    - 주소 검색 요청 형식과 결과 입력, 로고가 버튼에 가리지 않는지
    - SDK를 못 불러오거나 WebGL이 없을 때의 대체 지도
    - 키가 없을 때 이전과 같은 OpenStreetMap 동작
  - 이전 기능 320개는 그대로 통과했습니다. 키가 없는 상태라 OpenStreetMap으로 동작합니다.
  - 영어·일본어 번역 누락 점검도 했습니다. 남은 것은 테스트용 한국어 지명뿐입니다.
- **미검증 (작업 환경에서 외부 인터넷 접속 불가):**
  - 실제 MapTiler 서버, 실제 키
  - 실제 CDN 파일 다운로드 (`cdn.maptiler.com`의 SDK v3.11.2, jsdelivr의 플러그인 4.1.1)
  - 실제 지도 모양, 아이폰 Safari/PWA
  - 키를 넣은 뒤 위 5번처럼 상세 지도가 뜨는지 꼭 확인해 주세요. 안 뜨더라도 대체 지도(MapTiler 지도 이미지)로 보입니다.
