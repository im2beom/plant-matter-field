# RAINFOREST MEMORIES BY PLANT MATTER — BETA 11

## BETA 10에서 변경된 내용

### 타이틀 이미지
- 전달받은 이미지로 제목을 바꿨습니다.
  - 상단 로고: `RAINFOREST MEMORIES / Designed by PLANT MATTER`
  - HOME: `RAINFOREST MEMORIES`
  - MAP: `FIELD MAP`
  - PROFILE: `PROFILE`
  - OPTIONS: `OPTIONS`
  - RECORD: `NEW PLANT RECORD`
- **대분류 제목 5개는 글자 높이가 모두 같습니다.**
  - 원본 이미지의 대문자 높이(약 91px)를 재서 모두 같은 비율로 축소합니다.
  - 화면 너비에 따라 글자 높이는 21~28px 사이로 함께 바뀝니다.
- **상단 로고는 대분류보다 조금 작게** (대문자 높이 약 60~70%) 표시하고, BETA 표시와 겹치지 않게 했습니다.
- 흰 배경 JPG를 투명 PNG로 바꿔서 반투명 상단 바 위에서도 흰 박스가 보이지 않습니다.
- **NEW PLANT RECORD 이미지에 대해:**
  - 대화에 첨부된 이 이미지는 파일로 전달되지 않았습니다.
  - 그래서 같은 글꼴(Pretendard SemiBold, 자간 0.2em)로 다시 만들었습니다.
  - 같은 방식으로 PROFILE·OPTIONS·FIELD MAP을 만들어 원본과 비교하면 크기가 픽셀 단위로 같고, 글자 모양은 96~98% 일치합니다.
  - 원본 파일로 바꾸고 싶으면 `assets/titles/title-new-record.png`를 교체하면 됩니다.
- NEW PLANT RECORD는 한 줄이면 휴대폰 화면(약 383px)보다 넓어집니다. 그래서 **휴대폰에서는 `NEW PLANT / RECORD` 두 줄**로, 520px 이상 넓은 화면에서는 한 줄로 표시합니다. 두 줄일 때도 글자 크기는 다른 제목과 같습니다.

### 관찰 기록 사진: 식물 5장 + 주변 환경 2장
- **식물 사진 최대 5장**, **주변 환경 사진 최대 2장**을 올릴 수 있습니다.
  - 앨범에서는 여러 장을 한 번에 고를 수 있습니다.
  - 모두 가로 4:3으로 가운데를 기준으로 자동으로 잘립니다.
- 첫 번째 식물 사진이 대표 사진입니다.
  - 목록, 피드, 지도에 표시됩니다.
  - **대표로** 버튼으로 다른 사진을 대표로 바꾸고, **✕**로 뺄 수 있습니다.
- 입력 중인 사진도 임시 저장되어, 다른 탭에 다녀와도 그대로 남아 있습니다.
- **슬라이드 보기:** 관찰 기록 상세 화면 위쪽에서 사진을 옆으로 넘겨 봅니다.
  - "식물 사진 2/4", "주변 환경 1/2"처럼 지금 보는 사진이 표시되고, 점과 ‹ › 버튼으로도 넘길 수 있습니다.
  - 사진을 누르면 전체 화면 확대 보기가 열립니다.
- 공방 대표 사진 갤러리도 같은 슬라이드 방식으로 바꿨습니다.
- 사진이 2장 이상인 기록은 홈 피드 사진 오른쪽 아래에 `⧉ 5`처럼 장수가 표시됩니다.
- **온라인 공유:** 모든 사진이 업로드됩니다.
  - 이미 올린 사진은 다시 올리지 않습니다.
  - 수정하면서 뺀 사진은 서버에서도 삭제됩니다.
  - 비공개로 돌린 기록의 사진은 모든 사진이 다른 멤버에게 보이지 않습니다.
- 기존 기록의 사진 1장은 첫 번째 식물 사진으로 그대로 유지됩니다.

## 설치 순서

1. 기존 앱 **PROFILE → 데이터 백업 → JSON 내보내기**로 백업하세요.
2. ZIP을 풀어 GitHub에 업로드하세요. 새 폴더 `assets/titles`도 함께 올라가야 합니다.
   - 업로드 페이지: https://github.com/im2beom/plant-matter-field/upload/main
   - **`config.js`는 덮어쓰지 마세요.**
3. Supabase **SQL Editor**에서 실행하세요.
   - BETA 10까지 적용했다면: `supabase/beta11_observation_photos.sql`만 실행하면 됩니다.
   - 확실하지 않다면: `supabase/beta07_to_11_combined.sql`을 실행하세요. 여러 번 실행해도 안전합니다.
4. 앱 상단 로고 옆에 `BETA 11`이 보이는지 확인하세요.

**SQL 실행 전에는:**
- 타이틀 변경과 여러 장 사진 입력·슬라이드는 이 기기에서 바로 작동합니다.
- 다만 온라인 공유에는 대표 사진 1장만 올라갑니다.

## 검증 범위

- **SQL:** 로컬 PostgreSQL 16(Supabase 구조 모사)에서 확인했습니다.
  - BETA 11 SQL 2회 실행, 07~11 통합 SQL 반복 실행 모두 정상
  - 기존 사진이 새 목록의 첫 번째로 옮겨짐
  - 식물 사진 6장은 거부됨
  - 다른 멤버는 추가 사진·주변 환경 사진을 볼 수 있지만, 기록을 비공개로 돌리면 볼 수 없음
- **화면:** Playwright(Chromium) 자동 테스트 177개 항목과 오프라인 테스트를 모두 통과했습니다.
  - BETA 11 새 기능 27개
    - 320·390·768px 화면에서 제목 5개가 같은 크기인지, 화면을 넘지 않는지, 상단 로고가 더 작고 BETA 표시와 겹치지 않는지
    - 사진 5장·2장 제한, 대표 지정과 삭제, 임시 저장 복구
    - 슬라이드 넘김과 표시, 확대 보기
    - 업로드 6장, 수정할 때 다시 올리지 않고 뺀 사진만 삭제
    - 다른 멤버 기록의 슬라이드, 피드의 장수 표시
  - 이전 기능 회귀 테스트 150개
  - 영어·일본어 번역 누락 점검
- **미검증:**
  - 실제 Supabase 적용
  - 아이폰 Safari/PWA에서 슬라이드 스와이프와 여러 장 선택 실기기 확인
