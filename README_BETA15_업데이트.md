# RAINFOREST MEMORIES BY PLANT MATTER — BETA 15

## 한 줄 요약
앱을 **내가 키우는 식물 관리 + 야생에서 발견한 식물 기록** 두 가지로 좁혔습니다.
지도는 모두 뺐고, 하단 탭은 **HOME · PLANT · MATTER · OPTION** 네 개입니다.

## 바뀐 내용

### 1. 지도 관련 기능 전부 삭제
- **없어진 것:**
  - MAP 탭, 탐사(경로) 기능
  - 공간·공방·매장 등록(운영자 계정과 개인 공간 모두), 보유 식물의 "분양 상태"
  - 위치 선택 지도, 상세 화면 작은 지도, 주소 검색, MapTiler, 도법 설정
- **홈 화면:** 피드와 랭킹을 뺐습니다.
- **그대로인 기능:** 친구, 도감, 좋아요, 댓글, 동정 의견, 백업, 언어 설정
- **데이터는 지우지 않았습니다.** 예전 공간·탐사·좌표·분양 상태는 데이터베이스에 그대로 있고 화면에만 나오지 않습니다.
- **MapTiler 키는 이제 필요 없습니다.**
  - `config.js`의 `maptilerKey` 줄은 지워도 되고, 남겨 두어도 문제없습니다.
  - MapTiler 계정의 키도 삭제해도 됩니다.

### 2. 야생 발견 기록은 "나라"까지만
- GPS, 장소 이름, 위치 공개 범위 입력이 없어졌습니다.
- 나라는 직접 쓰지 않고 목록에서 고릅니다: **넓은 지역 → 나라**.
  - 검색창에 한국어·영어·일본어 이름 일부를 쳐도 찾습니다. 예: "말레", "Borneo"
  - 최근에 고른 곳이 위에 나옵니다.
- 서버로 공유되는 기록에는 좌표와 장소 이름이 들어가지 않습니다.
- 예전 기록은 다른 사람에게 나라만 보입니다.
  - 예전에 "위치 비공개"로 저장한 기록은 계속 "비공개"로 보입니다.

### 3. PLANT 탭
**My Plants (내 식물)**
- 참고 이미지처럼 큰 글씨 분류 목록입니다.
  - 각 분류 옆에 개수가 붙고, 비어 있는 분류는 연한 회색입니다.
  - 오른쪽 아래에 전체 개수(All)가 크게 나옵니다.
- 기본 분류 9개: Orchid, Caudex, Jungle Plants, Staghorn Fern, Bromeliad, 유묘 / 파종, 선인장, Tropical Plants, Tillandsia
  - 계정마다 한 번만 만들어집니다. 처음 만들 때의 앱 언어를 따릅니다.
- 분류를 누르면 **하위 목록**이 열립니다. 하위 목록에서 할 수 있는 일:
  - **＋ 식물**: 그 분류에 바로 식물 추가
  - **＋ 하위 분류**: 예) Orchid › Bulbophyllum. 2단계까지 만들 수 있습니다.
  - **이름 변경 / 삭제**: 분류를 지우면 들어 있던 식물은 "미분류"로 옮겨집니다.
- 분류가 없는 식물(예전에 등록한 식물 포함)은 "미분류"에 모입니다.

**식물 등록 화면**
- **원산지:** 넓은 지역 10곳 → 나라 또는 섬·지역 순서로 고릅니다.
  - 지역: 동남아시아, 동아시아, 남아시아, 오세아니아, 아프리카, 중동·서아시아, 유럽, 북아메리카, 중앙아메리카·카리브, 남아메리카
  - 섬·지역: 보르네오, 수마트라, 술라웨시, 자바, 뉴기니, 소코트라, 아마존, 안데스
  - "동남아시아 전체"처럼 지역까지만 골라도 됩니다.
  - 예전에 글로 적은 원산지는 그대로 보입니다.
- **모본(♀) / 부본(♂):** 내 식물 중에서 고르거나 직접 입력합니다.
  - 둘 다 정하면 이름 칸에 **"모본 × 부본"**이 자동으로 들어갑니다.
  - 이름을 직접 고친 뒤에는 자동으로 덮어쓰지 않습니다.
  - 부모 식물 상세 화면에 **"이 식물의 자손"** 목록이 나옵니다.
  - 부모 식물을 지워도 자손에 적힌 부모 이름은 남습니다.
- "보관 위치"와 "분양 상태" 칸은 없습니다.

**Wild Finds (야생 발견)**
- 지역 → 나라 → 기록 순서의 목록입니다.
- 오른쪽 위 ＋로 새 기록을 추가합니다.
- 나라를 정하지 않은 예전 기록은 "국가 미지정"에 모입니다.

### 4. MATTER 탭
- **EVENT:** 식물 행사 목록입니다. 라임색 화면이고, 굵은 제목과 가는 부제를 씁니다.
  - 다가오는 행사가 날짜 순으로 나옵니다.
  - 지난 행사는 아래에 흐리게 나옵니다.
- **SHOP LIST:** 식물 매장, 쇼룸, 온실 등의 목록입니다.
  - 주소의 **"지도 앱에서 열기"**를 누르면 외부 지도 앱이 열립니다. 한국어는 네이버 지도, 그 밖의 언어는 구글 지도입니다. 앱 안에는 지도가 없습니다.
  - 인스타그램, 전화, 웹사이트 링크를 넣을 수 있습니다.
- **누구나 볼 수 있습니다.** 로그인하지 않아도 됩니다.
- **등록·수정·삭제는 관리자만 할 수 있습니다.** 아래 "관리자 지정"을 참고하세요.

### 5. HOME
- 다가오는 행사의 **첫 번째 포스터**를 화면 가득 보여 줍니다. 가까운 날짜가 먼저입니다.
  - 손가락으로 넘깁니다. 자동으로 넘어가지 않습니다.
  - 포스터를 누르면 그 행사 상세 화면이 열립니다.
- 다가오는 행사가 없으면 RAINFOREST MEMORIES 로고 화면이 나옵니다.
- 행사 정보를 불러오지 못하면(오프라인 등) 이 기기에 마지막으로 받은 내용을 보여 줍니다.
- 오른쪽 위 ☰를 누르면 OPTION으로 갑니다.

### 6. OPTION
목록: Profile · Friends · Backup · Language · Account · About
- 친구 요청이 오면 Friends와 OPTION 탭에 빨간 표시가 붙습니다.
- 계정 종류에서 "공간 운영" 선택지는 없어졌습니다.

### 7. 글꼴과 크기
- **영문·숫자:** Figtree
  - 본문 Light 300, 강조 Bold 700
  - 큰 숫자(All 개수 등)는 ExtraBold 800
- **한글:** Noto Sans KR (Light 300, Bold 700)
- 이번 요청대로 전체 글씨를 조금 줄였습니다. 큰 제목 기준으로 약 15% 작아졌습니다.
- 글꼴은 Google Fonts에서 필요한 굵기만 받습니다. 이전에 쓰던 Pretendard는 더 이상 불러오지 않습니다.

## 설치 순서
1. 기존 앱 **PROFILE → 데이터 백업 → JSON 내보내기**로 백업하세요.
2. ZIP을 풀어 GitHub에 올리세요. **`config.js`는 덮어쓰지 마세요.** (ZIP에 들어 있지 않습니다.)
3. GitHub에서 더 이상 쓰지 않는 파일을 지워 주세요. 남아 있어도 앱은 작동합니다.
   - `assets/js/` 폴더 전체 (MapTiler·Leaflet 파일)
   - `assets/landPath.json`
   - `assets/geo/borders.json`
   - `supabase/beta07_to_13_combined.sql` (→ `beta07_to_15_combined.sql`로 바뀌었습니다)
4. Supabase **SQL Editor**에서 **`supabase/beta15_plants_matter.sql`**을 한 번 실행하세요.
   - BETA 13 SQL까지 실행한 상태여야 합니다. BETA 14는 SQL이 없었습니다.
   - 여러 번 실행해도 안전합니다.
   - 새 Supabase 프로젝트라면 `supabase/beta07_to_15_combined.sql` 하나로 충분합니다.
5. 아래 **관리자 지정**을 실행하세요.
6. 앱을 새로고침해서 상단 로고 옆에 `BETA 15`가 보이는지 확인하세요.
   - 예전 화면이 보이면 한 번 더 새로고침하거나, 홈 화면 앱을 껐다 켜 주세요.

## 관리자 지정 (행사·매장 등록용)
`YOUR_LOGIN_EMAIL`을 앱에 로그인할 때 쓰는 이메일로 바꾼 뒤 SQL Editor에서 실행하세요.
```sql
insert into public.app_admins (user_id) select id from auth.users where lower(email) = lower('YOUR_LOGIN_EMAIL') on conflict do nothing;
-- 확인: 내 이메일이 보이면 성공
select u.email from public.app_admins a join auth.users u on u.id = a.user_id;
```
- 관리자 목록은 SQL Editor에서만 바꿀 수 있습니다. 앱이나 API로는 바꿀 수 없습니다.
- 관리자를 빼려면 `delete from public.app_admins where user_id = (select id from auth.users where lower(email) = lower('이메일'));`를 실행하세요.

## 행사·매장 등록 방법 (관리자)
1. **MATTER → Event** (또는 **Shop List**)로 들어갑니다.
2. 오른쪽 위 **＋**를 누릅니다.
3. **행사:**
   - 포스터를 최대 6장 넣습니다.
     - **첫 장이 HOME 포스터**가 됩니다.
     - 자르지 않고 저장합니다. 긴 변 2000px JPEG로 줄입니다.
     - HOME 화면에는 세로 9:16 이미지가 가장 잘 맞습니다.
   - 굵은 제목, 가는 부제, 시작일, 종료일(하루짜리면 비움), 장소, 소개, 링크를 넣습니다.
4. **매장:**
   - 사진을 최대 10장 넣습니다.
   - 이름, 종류(매장/쇼룸/온실/기타), 지역, 주소, 운영 시간, 전화, 인스타그램, 웹사이트, 소개, 목록 순서를 넣습니다.
5. 링크와 웹사이트는 `https://`로 시작해야 저장됩니다.
6. 수정·삭제는 상세 화면 아래 **수정 / 삭제** 버튼으로 합니다. 삭제하면 사진 파일도 함께 지워집니다.
- 포스터와 매장 사진은 공개 저장소(`matter-media`)에 올라가서 누구나 볼 수 있습니다. **개인 사진은 올리지 마세요.**

## SQL을 실행하기 전에 앱을 열면
- **My Plants:** "beta15_plants_matter.sql을 실행해 주세요" 안내가 나옵니다.
  - 식물 저장은 됩니다. 분류, 원산지 선택, 부모 정보만 빠집니다.
- **MATTER:** 로그인한 테스터에게 같은 안내가 나옵니다.
- **HOME:** 행사가 없으므로 로고 화면이 나옵니다.

## 알아 두실 점
- **예전 발견 기록 수정:** 좌표가 있는 예전 기록을 수정해서 다시 저장하면, 서버의 공유본에서는 좌표가 빠집니다.
  - 이 기기 안의 기록과 JSON 백업에는 좌표가 그대로 남습니다.
  - 수정하지 않은 예전 기록은 서버에서도 그대로입니다. 화면에만 나라로 보입니다.
- **백업 파일:** 예전에 저장한 위치 정보가 들어 있을 수 있으니 안전한 곳에 보관하세요.
- **개인정보 안내(privacy.html) 4-1 항목**을 "발견 장소와 공개 정보"로 바꿨습니다.
  - 나라 단위만 저장한다는 점, 행사·매장 정보가 공개된다는 점, 지도·주소 검색이 없다는 점을 적었습니다.
  - 정식 방침을 만들 때 검토해 주세요.

## 검증 범위
- **자동 테스트 159개 모두 통과** (Playwright Chromium, 아이폰 크기 390px, 가짜 Supabase 서버)
  - **BETA 15 기능 100개**
    - 탭 4개, 지도·외부 지도 요청이 전혀 없는지
    - 나라 선택과 공유본에 좌표가 없는지
    - 분류·하위 분류·이름 변경·삭제, 원산지 선택, 모본×부본 자동 이름, 자손 목록
    - 행사·매장 보기, 관리자 등록·수정·삭제, 비관리자·로그아웃 상태, 포스터 원본 비율 유지
    - HOME 포스터 순서·넘김·오프라인, SQL 미실행 상태
  - **유지된 기능 37개:** 좋아요, 댓글, 동정 의견, 사진 크게 보기, 친구 수락, 발견 기록 수정·비공개·삭제, 작성 중 내용 유지, 오프라인 저장 후 업로드, 백업 내보내기·가져오기, 로그아웃, 영어·일본어
  - **화면 폭 검사 22개:** 320px, 430px에서 화면이 옆으로 넘치지 않는지
  - 영어·일본어로 모든 화면을 확인했습니다. 남은 한국어는 관리자가 입력한 행사 제목뿐입니다.
- **SQL:** 로컬 PostgreSQL 16(Supabase 함수 흉내)에서 확인했습니다.
  - 관리자만 쓰기 가능, 로그인 없이 읽기 가능, 링크·날짜 검사, 저장소 권한
  - 분류 2단계 제한, 남의 분류·남의 부모 식물 연결 차단
  - 여러 번 실행해도 안전한지
- **이전 버전 테스트:** 지도·공간·탐사 기능이 없어져서 BETA 14까지의 테스트는 은퇴시켰습니다. 남아 있는 기능은 위 37개 항목으로 다시 확인했습니다.
- **미검증:**
  - 실제 Supabase 서버에서의 SQL 실행과 관리자 업로드
  - 실제 아이폰 Safari / 홈 화면 앱
  - 네이버 지도·구글 지도 앱이 실제 휴대폰에서 열리는지

  (Google Fonts 글꼴 파일은 실제 서버에서 받아 테스트 화면에 적용해 확인했습니다.)
