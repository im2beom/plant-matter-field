# RAINFOREST MEMORIES BY PLANT MATTER — BETA 13

## BETA 12에서 변경된 내용

### 계정 표기
- **① "공간 운영자" → "공간 운영"** (영어 Venue, 일본어 スペース運営)
- **② 공간 이름 함께 표시:**
  - 운영 공간이 1곳이면 "공간 운영 · 책방의 게코"
  - 2곳 이상이면 "공간 운영 · 책방의 게코 외 1곳"
  - 표시되는 곳: 프로필 머리말, 도감 머리말, 친구·검색 목록, 발견 랭킹
  - 개인 공간은 세지 않습니다. 운영 공간이 없으면 "공간 운영"만 보입니다.
  - 좁은 화면에서도 "외 1곳"이 두 줄로 갈라지지 않습니다.

### 보유 식물
- **③ 공간 운영 → 개인 전환 시 보유 식물 유지:**
  - 확인 창: "운영 공간 N곳과 대표 사진이 삭제됩니다. 보유 식물 M개는 남고 '공간 미지정'으로 옮겨집니다."
  - 운영 공간과 대표 사진만 지워지고, 보유 식물과 그 사진은 남습니다.
- **공간 미지정:**
  - 공간이 없어도 보유 식물을 등록할 수 있습니다. 등록 화면에 **"공간 지정 안 함"**이 있습니다.
  - 나중에 공간을 만들면 수정 화면에서 공간으로 옮길 수 있습니다.
  - 다른 멤버의 도감에도 **"공간 미지정"** 묶음으로 보입니다.
  - 공간을 직접 삭제할 때도 보유 식물은 남고 "공간 미지정"으로 옮겨집니다. 확인 창에 개수가 나옵니다.
- **④ 보유 식물 공개 / 비공개:**
  - 등록 화면 **04 / SHARING**에서 "공개 / 비공개 · 나만 보기"를 고릅니다. 기본은 공개입니다.
  - 식물 상세와 "나의 보유 식물" 카드의 **[비공개로 전환] / [다시 공개]** 버튼으로 언제든 바꿀 수 있습니다.
  - 본인 화면에는 **"비공개"** 표시가 붙습니다.
  - 다른 멤버에게는 공간 화면, 도감, 지도 검색 어디에도 보이지 않습니다. 보유 종 수도 공개 식물만 셉니다.
  - 비공개 식물의 사진은 서버 저장소 규칙으로도 막힙니다.

### 지도 검색
- **⑤ 검색하면 결과에 맞춰 확대합니다:**
  - **나라 이름**(한국어·영어·일본어, 예: 말레이시아 / Malaysia / マレーシア): 그 나라가 화면에 꽉 차도록 확대하고, 그 나라의 기록과 공간만 보여 줍니다. 나라 경계는 기기 안의 자료를 씁니다.
  - **학명·장소 이름 등**: 검색된 핀이 모두 보이도록 맞춥니다. 결과가 1개면 가까이 확대합니다.
  - 이퀄 어스 지도로 부족하면 상세 지도로 자동 전환합니다. Web Mercator에서도 같습니다. 전체 화면 지도에서도 작동합니다.
  - 검색어를 지우면 보던 화면을 유지합니다.
  - 결과가 없으면 "검색 결과가 없습니다"만 띄우고 지도는 그대로 둡니다.

### 사진
- **⑥ 도감 사진 칸이 아이폰에서 밀리거나 잘리던 문제 수정:**
  - 사진을 칸에 꽉 채우고 가운데를 기준으로 자르는 방식으로 바꿨습니다.
  - 같은 방식을 기록 카드 썸네일, 보유 식물 카드, 겹친 핀 목록, 공간 관리·도감 공간·지도 팝업 사진에도 적용했습니다.
- **⑦ 사진 슬라이드가 가운데에 멈추지 않던 문제 수정:**
  - 한 번 넘기면 한 장씩만 넘어갑니다.
  - 사진 사이 간격을 없애고, 손을 뗀 뒤 멈추면 정확히 가운데에 맞춥니다.
  - 높이는 넘기는 동안 바뀌지 않고, 멈춘 뒤에 사진 비율에 맞춰 바뀝니다.
  - 관찰 기록, 공간 대표 사진, 보유 식물 슬라이드에 모두 적용됩니다.
- **⑧ 사진 올리기 화면 정리** (관찰 식물·주변 환경·보유 식물·공간 대표 사진·프로필 사진 모두):
  - 칸마다 **[▧ 앨범] [◉ 촬영]** 버튼이 따로 있습니다. 칸 사이의 공용 버튼은 없앴습니다.
  - 빈 칸은 작은 "＋" 칸에 개수(0/5, 0/2, 0/10)만 표시합니다. 다 채우면 버튼이 꺼집니다.
  - 안내 문구는 한 줄로 합쳤습니다. 예: "첫 사진이 대표 · 가로 16:9, 세로 3:4로 자동 자르기 · 위치가 드러나는 표지판은 피해 주세요"
  - 프로필 사진: "프로필 사진 · 1:1 정사각형으로 자동 자르기" (촬영은 전면 카메라)

### 화면
- **⑨ 상단 로고 25% 축소:** 휴대폰(390px) 기준 가로 약 273px → **약 205px**. 상단 바 높이도 76px → 60px로 낮췄습니다.
  - 320px 화면에서도 BETA 표시와 겹치지 않습니다.

## 설치 순서
1. 기존 앱 **PROFILE → 데이터 백업 → JSON 내보내기**로 백업하세요.
2. ZIP을 풀어 GitHub에 업로드하세요. **`config.js`는 덮어쓰지 마세요.**
3. Supabase SQL Editor에서 실행하세요.
   - BETA 12까지 적용했다면: `supabase/beta13_kept_plants_visibility.sql`
   - 확실하지 않다면: `supabase/beta07_to_13_combined.sql` (여러 번 실행해도 안전)
4. 상단에 `BETA 13`이 보이는지 확인하세요.

**SQL 실행 전에는:**
- 표기, 지도 검색, 사진 칸, 슬라이드, 사진 올리기, 로고 크기는 그대로 작동합니다.
- "공간 지정 안 함", 공개/비공개 선택, 전환 버튼 대신 SQL 안내가 보입니다.
- 보유 식물이 있는 운영 공간에서 개인으로 전환하면 SQL 안내만 뜨고 아무것도 지우지 않습니다. 이전 SQL로는 식물까지 지워지기 때문입니다.

## 검증 범위
- **SQL:** 로컬 PostgreSQL 16(Supabase 구조 모사)에서 확인했습니다.
  - BETA 13 SQL 2회 실행, 07~13 통합 SQL 반복 실행(새 DB·기존 DB) 모두 정상
  - 공간 없는 보유 식물 등록 가능. 남의 공간에 식물을 넣거나 옮길 수 없음
  - 비공개 식물과 그 사진은 다른 멤버가 볼 수 없음. 남의 식물 공개 상태를 바꿀 수 없음
  - 개인 전환 시 운영 공간만 삭제, 식물은 공간 미지정으로 남고 비공개 상태 유지. 대표 사진 경로만 반환
  - 공간을 삭제해도 식물은 남음
- **화면:** Playwright(Chromium, 아이폰 크기) 자동 테스트 **320개 항목** 모두 통과
  - BETA 13 새 기능 86개 (요청 9개 각각, SQL 적용 전 상태 포함)
  - 이전 기능 234개 (의도한 변경에 맞춰 7개 항목의 기대값 수정: "공간 운영" 표기, "공간 지정 안 함" 선택지, 전환 시 식물 유지, 결과 1개 검색 시 확대)
  - 슬라이드는 터치 스와이프로 확인: 한 장씩, 가운데 정렬 오차 1px 미만, 멈춘 뒤에만 높이 변경
  - 영어·일본어 번역 누락 점검 (남은 것은 테스트용 한국어 지명뿐)
- **미검증:** 실제 Supabase 적용, 아이폰 Safari/PWA 실기기
  - ⑥ 사진 칸과 ⑦ 슬라이드는 아이폰에서 꼭 확인해 주세요. 테스트 환경에는 Safari 엔진이 없습니다.
