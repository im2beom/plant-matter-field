# RAINFOREST MEMORIES BY PLANT MATTER — BETA 10

## BETA 09에서 변경된 내용

### 언어 전환 버그 수정
- **원인:** 하단 탭, 상단 로고, 버튼 설명처럼 다시 그려지지 않는 부분은 번역할 때 글자를 제자리에서 바꿔 썼습니다. 그래서 다음 전환에서 원문(한국어)을 찾지 못했습니다.
  - 예: 영어 → 일본어로 바꾸면 하단 탭이 영어로 남았습니다.
  - 예: 영어 → 한국어로 바꾸면 영어로 남았습니다.
  - 전환 순서에 따라 생겨서 간헐적으로 보였습니다.
- **수정:** 모든 글자의 한국어 원문을 기억해 두고, 어떤 순서로 바꿔도 원문에서 번역하도록 바꿨습니다.
- **빠진 번역 보충:** 모든 화면을 자동으로 훑어 번역이 빠진 문구 약 80개를 찾아 영어·일본어를 추가했습니다.
  - 대상: 지도, 기록 입력, 탐사 경로, 백업, 설정, 상세 화면, 알림 메시지 등
  - 지금 남은 한국어는 이용자가 입력한 지명·공간 이름뿐입니다.

### 계정 유형: 개인 / 공간 운영자
- **PROFILE → 내 프로필 → 계정 유형**에서 본인이 언제든 바꿀 수 있습니다.
- **개인** 카테고리 3가지:
  - **수집가:** 희귀·관심 식물을 모으고 관리
  - **재배가:** 번식·재배·실내 가드닝
  - **탐사가:** 자생지를 찾아 관찰·기록
- **공간 운영자** 공간 카테고리 4가지: **매장·쇼룸 / 온실·농장 / 문화공간·전시 / 연구·교육시설**
  - "및" 대신 가운뎃점(·)을 썼습니다. 더 짧고 앱의 다른 표기와 맞습니다. 띄어쓰기 없는 `매장·쇼룸`은 한 카테고리, 띄어 쓴 ` · `는 항목 구분으로 구별됩니다.
  - **공간 카테고리 선택은 공간 운영자에게만 보입니다.**
- 계정 유형은 프로필, 도감, 친구 검색 결과, 발견 랭킹에 표시됩니다.
- 이미 공간을 등록한 기존 회원은 SQL을 처음 실행할 때 자동으로 "공간 운영자"가 됩니다. 이후에는 본인이 바꿀 수 있습니다.
- 기존 공방·매장·작업실 공간은 "(이전 분류)"로 그대로 유지되고, 수정할 때 새 카테고리로 바꿀 수 있습니다.

### 개인 공간 (지역 단위)
- 개인도 **나의 공간**(집·베란다·개인 온실 등)을 **대표 사진(최대 10장)**과 함께 등록할 수 있습니다.
- 위치는 **서울, 경기처럼 시·도 같은 큰 지역만** 검색해서 고릅니다.
  - 상세 주소 칸이 없습니다.
  - 지도를 눌러 핀을 옮길 수 없습니다.
  - 좌표는 지역 중심으로만 저장됩니다.
- 상세 화면에는 "활동 지역"만 표시되고 길찾기 버튼은 없습니다.
- 서버에서도 개인 공간에는 상세 주소를 저장할 수 없게 막았습니다.

### 나의 보유 식물 분리
- PROFILE → 내 프로필에 **나의 보유 식물** 항목을 따로 만들었습니다. 식물 공간 항목 바로 아래에 있습니다.
- 공간별로 묶어서 보여 주고, 여기서 바로 등록·수정·삭제할 수 있습니다.
- 공간이 여러 개면 어느 공간에 등록할지 고를 수 있습니다.
- 식물 공간 목록에는 대표 사진과 공간 관리 버튼만 남겼습니다.

### 홈 화면
- **발견 랭킹:** 공유된 발견 기록 수 기준 상위 5명(펼치면 10명)을 보여 줍니다.
  - 각 사람의 발견 수와 종 수, 계정 유형이 함께 표시됩니다.
  - 누르면 그 사람의 도감이 열립니다.
  - 비공개로 돌린 기록은 랭킹에 들어가지 않습니다.
- "인기 식물" 제목을 **"기록된 식물"**로 바꿨습니다. 좋아요 순과 최신순 정렬은 그대로입니다.

### 지도
- 작은 지도에서 확대하거나 옮긴 위치가 **전체 화면 지도에서도 그대로 이어집니다.** 전체 화면을 닫을 때도 마찬가지입니다.
- 상세 지도에서 세계 지도로 돌아가면, 보고 있던 위치를 중심으로 돌아갑니다.
- 메르카토르 지도의 **＋ 확대 버튼이 지도 이름표에 가려 눌리지 않던 문제**를 고쳤습니다. 확대·축소 버튼을 오른쪽 위로 옮겼습니다.

## 설치 순서

1. 기존 앱 **PROFILE → 데이터 백업 → JSON 내보내기**로 백업하세요.
2. ZIP을 풀어 GitHub에 업로드하세요.
   - 업로드 페이지: https://github.com/im2beom/plant-matter-field/upload/main
   - **`config.js`는 덮어쓰지 마세요.**
3. Supabase **SQL Editor**에서 실행하세요.
   - BETA 07~09 SQL을 이미 실행했다면: `supabase/beta10_accounts_ranking.sql`만 실행하면 됩니다.
   - 확실하지 않다면: `supabase/beta07_to_10_combined.sql`을 실행하세요. 여러 번 실행해도 안전합니다.
4. 앱 상단에 `BETA 10`이 보이는지 확인하세요.

**SQL 실행 전에는:**
- 언어 수정, 화면 구성, 지도 동기화는 바로 적용됩니다.
- 계정 유형 선택에는 SQL 안내가 뜹니다.
- 공간 등록은 이전 분류(공방·매장·작업실)로 동작합니다.
- 발견 랭킹은 이 기기에 불러온 기록 기준의 임시 순위로 표시됩니다.

## 검증 범위

- **SQL:** 로컬 PostgreSQL 16(Supabase 구조 모사)에서 확인했습니다.
  - BETA 10 SQL 2회 실행, 07~10 통합 SQL 3회 반복 실행 모두 정상
  - 랭킹: 비공개 기록 제외, 같은 학명은 대소문자가 달라도 같은 종으로 계산, 초대받지 않은 계정은 결과 없음
  - 허용되지 않은 카테고리나 계정 유형 값은 거부됨
  - 개인 공간에 상세 주소 저장은 거부됨
  - 기존 공간 소유자가 자동으로 운영자로 바뀌는 것은 처음 실행할 때만 일어남
- **화면:** Playwright(Chromium, 아이폰 크기 화면) 자동 테스트 150개 항목을 모두 통과했습니다.
  - BETA 10 새 기능 28개
    - 언어를 한·영·일 사이에서 여러 순서로 전환
    - 계정 유형·카테고리 변경
    - 개인 공간의 지역 검색과 핀 고정
    - 운영자 카테고리 4종
    - 보유 식물 분리 항목
    - 발견 랭킹
    - 전체 화면 지도의 확대 상태 유지, 확대 버튼이 가려지지 않는지
  - 이전 기능 회귀 테스트 122개
  - 오프라인 상황 테스트
  - 영어·일본어로 모든 화면을 훑어 번역 누락 확인
- **미검증:**
  - 실제 Supabase 적용
  - 실제 주소 검색의 "지역" 결과 품질 (Nominatim)
  - 아이폰 실기기 확인
